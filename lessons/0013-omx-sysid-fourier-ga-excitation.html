多级傅里叶激励轨迹 + GA 求解系数

第 6 课讲了固定模板（1/k 谐波权重）的傅里叶 q(t)。 本课补上两层：多级傅里叶在工程里怎么算 q、q̇、q̈，以及 遗传算法（GA）如何离线搜索幅值 a 与相位 φ，使辨识观测矩阵更好条件。 代码在 excitation_trajectory.py 与 excitation_ga.py；在线 Gazebo/实机默认读 config/excitation_ga.yaml。

主参考：Swevers J. et al., «Optimal robot excitation for parameter identification of robot dynamics», Robotica, 1997（DOI）。 仓库 RESOURCES.md 亦有收录。

1. 多级傅里叶：一条式子，三个量

对 OMX 四轴 Arm 的每个关节 j（joint1–4），Phase 1 用位置正弦级数（N 个谐波，基频 ω₀=2π/T）：

q_j(t) = q₀_j + Σ_{k=1}^{N} a_{jk} sin(k ω₀ t + φ_{jk})
q̇_j   = Σ a_{jk} · k ω₀ · cos(k ω₀ t + φ_{jk})
q̈_j   = −Σ a_{jk} · (k ω₀)² · sin(k ω₀ t + φ_{jk})

「多级」即 k=1…N 多个频率同时存在；N=5、T=10 s 时最低频 0.1 Hz，最高谐波 0.5 Hz。 相比单频正弦，Y(q,q̇,q̈) 各列更易持续激励，回归更稳定。

工程入口：compute_joint_kinematics()（纯数学，无 ROS）

def compute_joint_kinematics(q0, amplitudes, phases, omega0, time_s):
    q, qd, qdd = q0, 0.0, 0.0
    for k, (amp, phase) in enumerate(zip(amplitudes, phases), start=1):
        omega = k * omega0
        angle = omega * time_s + phase
        q   += amp * sin(angle)
        qd  += amp * omega * cos(angle)
        qdd += -amp * omega**2 * sin(angle)
    return q, qd, qdd

ExcitationTrajectory.sample(t) 对四个关节各调一次，返回 TrajectorySample(position, velocity, acceleration)。

2. 两种系数来源：template vs ga

模式yaml 键系数从哪来用途
template excitation.yaml _build_harmonics()：a_k ∝ 1/k，φ=0 对照、调试、GA 种群种子
ga excitation_ga.yaml ga_coefficients 每关节 N 个 a、φ 默认在线激励（Gazebo / 实机） 
# excitation.yaml
excitation:
  coefficients_source: template   # 或 ga

# excitation_ga.yaml 额外段
ga_coefficients:
  joint1:
    amplitudes: [a1, a2, a3, a4, a5]
    phases:     [φ1, φ2, φ3, φ4, φ5]
ga_amplitude_scale: 1.0   # 幅值已写入 ga_coefficients 时为 1

无论哪种模式，构造后都会走同一套安全链： 软限位内缩 10%、|q̇|≤1.0 rad/s、|q̈|≤2.0 rad/s²； template 模式还会乘统一 amplitude_scale（_compute_amplitude_scale()）。

3. 在线轨迹：不只傅里叶段

build_excitation_trajectory_messages() 拼完整时间轴：

阶段时长内容
approach≥5 s（可延长）五次多项式从当前 q → q₀
hold2 s静止在 q₀
excitation1×T 或更多多级傅里叶（本课核心）
settle2 s回到 q₀，末端速度为 0

excitation_runner 把采样序列打成 FollowJointTrajectory goal 发给 arm_controller；launch 默认 config:=…/excitation_ga.yaml。

4. GA 在优化什么？

辨识线性式：Y(q,q̇,q̈) · π = τ。若 Y 列近似线性相关，最小二乘病态（条件数 κ 很大）。

Swevers 思路：选 q(t) 使堆叠观测矩阵 W 的条件数尽量小。 本仓库 GA 的适应度即 κ(W)（越小越好）；W 在一个周期内密采样堆叠而成。

5. 工程：观测矩阵 W 怎么建

excitation_ga.build_observation_matrix()

  1. 对轨迹上 num_samples 个时刻 t，调用 trajectory.sample(t) 得 q、q̇、q̈。
  2. 填入 Pinocchio 全模型状态，调用 pin.computeJointTorqueRegressor(model, data, q, q̇, q̈)。
  3. 取 Arm 四行（joint1–4），并拼接摩擦块 diag(q̇) 与 diag(sign(q̇))（Fv、Fc 列）。
  4. 各行垂直堆叠 → 矩阵 W；SVD 得有效秩与 κ。

违反软限位或速度/加速度 cap 的个体 → 适应度罚分 1e12，相当于淘汰。

6. 工程：GA 个体编码与进化

染色体长度：4 关节 × N 谐波 × 2（幅值基因 + 相位基因）= 40（N=5）。

基因取值解码
幅值基因 g_a[0, 1]a = g_a × template 最大幅值（1/k 分配）
相位基因 g_φ[0, 1]φ = g_φ × 2π

种群：第 1 个个体 = template（全 1、相位 0）；其余在 template 附近随机扰动。

每代：评估适应度 → 保留 elite（默认 4）→ 锦标赛选择 → 单点交叉 → 高斯变异 → 下一代。

默认 GAParameters：population=80，generations=120，samples_per_period=60。

CLI（Docker 内）：

ros2 run open_manipulator_sysid excitation_ga_optimize
ros2 run open_manipulator_sysid excitation_ga_optimize --quick   # 冒烟
ros2 run open_manipulator_sysid excitation_ga_optimize --generations 200

输出 config/excitation_ga.yaml，含 ga_metadata.condition_number 供验收对比。
