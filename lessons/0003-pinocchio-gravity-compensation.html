用 Pinocchio 实现 OpenMANIPULATOR 重力补偿

目标：给定当前关节角 q，算出 g(q)，在关节力矩接口上施加 τ = g(q)， 让机械臂在重力下近似「失重」——与 ROBOTIS open_manipulator_controls 的 KDL 版同一物理问题，换 Pinocchio 实现。

1. 物理问题：你在补偿什么？

拉格朗日动力学： M(q)q̈ + c(q,q̇) + g(q) = τ

静止、不加速时（q̈ = 0, q̇ = 0）：τ = g(q) 即可平衡重力。 这里的 g(q) 就是 generalized gravity——每个关节为抵抗重力所需力矩。

与第 2 课联系：重力在各 link 上产生 Wrench；Pinocchio 在 URDF 惯性参数上递归算出等效的 g(q)。

2. ROBOTIS 参考实现（KDL，ROS1）

open_manipulator_controls 中控制环极简（概念层）：

  1. 从 URDF 建 KDL chain（root_link → tip_link）
  2. 读当前关节位置 q
  3. ChainDynParam::JntToGravity(q, G)
  4. effort_joint_handle.setCommand(G(i))

前置条件（README）： EffortJointInterface、仿真时 transmission 设为 effort、电机 current 模式。 Launch：gravity_compensation_controller.launch sim:=false

你当前 ROS 2 仓库里的 om_gravity_compensation_controller 用 KDL 完整 RNEA， 还含摩擦补偿、leader 同步——比 ROBOTIS 参考版复杂。本课先掌握「纯 g(q)」核心。

3. Pinocchio 等价 API

Pinocchio 提供专用函数（见 文档）： 

#include <pinocchio/parsers/urdf.hpp>
#include <pinocchio/algorithm/rnea.hpp>

pinocchio::Model model;
pinocchio::urdf::buildModel("open_manipulator_x.urdf", model);
pinocchio::Data data(model);

Eigen::VectorXd q(model.nq);   // 当前关节构型
// ... 从 /joint_states 填入 q ...

pinocchio::computeGeneralizedGravity(model, data, q);
Eigen::VectorXd tau_g = data.g;   // τ = g(q)

// 等价写法（v=0, a=0 的 RNEA）：
pinocchio::rnea(model, data, q,
  Eigen::VectorXd::Zero(model.nv),
  Eigen::VectorXd::Zero(model.nv));
// data.tau == data.g

默认重力：model.gravity.linear() = (0, 0, -9.81)，与 KDL 里 KDL::Vector(0,0,-9.81) 一致。

6. 常见坑

  • nq / nv 与 arm 四关节：URDF 含 gripper、mimic 时 model.nv 可能 > 4；应对照 Pinocchio 打印的 joint 名，只补偿 arm 对应索引。
  • 符号：g(q) 与 Dynamixel 力矩正方向可能差负号；实机需小力矩阶跃校准。
  • 接口：当前 OMX 默认 open_manipulator_x_position 是位置模式；重力补偿需 effort/current 模式 与对应 ros2_control 插件（参考 ROBOTIS README）。
  • URDF 惯性：g(q) 完全依赖 link 的 mass/inertia；mesh 不对但 inertia 对即可。
