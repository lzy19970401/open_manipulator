OpenMANIPULATOR-X 参数辨识：离线回归 regress.py

已更新：当前 regress.py 改为 URDF 惯性固定、只估摩擦（8 维）。 请以 第 8 课 为准；本课保留作「68 维联合回归」历史对照。

第 6 课生成了激励轨迹 q(t), q̇, q̈。本课走读 Issue 02： 用 Pinocchio 把动力学写成线性回归 Y·π = τ， 在合成数据集上最小二乘估计 BIP + Fv + Fc， 输出只读 yaml 与 HTML 报告。源码： open_manipulator_sysid/regress.py。

与第 6 课的衔接：第 6 课回答「怎么动」；本课回答「动完之后，如何从 τ 反推模型参数」。 入口 CLI：ros2 run open_manipulator_sysid sysid_regress_synthetic。

1. 一条命令里发生了什么？

main() → run_synthetic_regression() 串联四步：

步骤函数输入 → 输出
1 建模 load_model() URDF → Pinocchio model, data（含 arm + gripper 共 nv=6）
2 合成数据 generate_synthetic_dataset() 第 6 课轨迹 + RNEA + 摩擦 + 噪声 → 堆叠矩阵 Y 与向量 τ
3 回归 solve_least_squares() π̂ = argmin ||Yπ − τ||（numpy.linalg.lstsq）
4 写结果 write_*_yaml(), write_report_html() results/bip_estimated.yaml、friction_estimated.yaml、report.html

2. 底层数学：从 M(q)q̈ + … = τ 到 Y·π = τ

M(q) q̈ + C(q,q̇) q̇ + G(q) + F(q̇) = τ

对固定拓扑的串联臂，上式对惯性参数是线性的。Pinocchio 把惯性部分打包成标准参数向量 φ（每连杆 10 维），并给出回归矩阵：

τdyn = Ydyn(q, q̇, q̈) · φ

代码里一行调用（build_regressor_row）：

dynamic = pin.computeJointTorqueRegressor(model, data, q, velocity, acceleration)

对 OMX 全 URDF，Y_dyn 形状为 (6, 60)：6 个速度自由度 × 6 个刚体 × 10 个标准惯性参数。 Phase 1 只取 Arm 四行 dynamic[arm_indices, :] 做辨识。

2.1 摩擦项：拼进 Y 的额外列

Phase 1 摩擦模型（每关节 i，不含 Jm）：

τf,i = Fvi · q̇i + Fci · sign(q̇i)

对四个 Arm 关节，把 Fv、Fc 也当作未知标量，回归矩阵横向拼接：

Y = [ Y_dyn,arm | diag(q̇_arm) | diag(sign(q̇_arm)) ]   # 形状 (4, 60+4+4) = (4, 68)
π = [ φ ; Fv₁…Fv₄ ; Fc₁…Fc₄ ]                            # 长度 68

对应代码（build_regressor_row）：

np.hstack([
    dynamic[arm_indices, :],
    np.diag(arm_velocity),
    np.diag(velocity_sign(arm_velocity)),
])

velocity_sign 在 |q̇| < 1e-3 时返回 0，避免静止点 sign 不定义；这是工程近似，不是物理 stiction 模型。

2.2 名义参数从哪来？

量代码来源
φ 名义（BIP）nominal_dynamic_parameters()各连杆 model.inertias[i].toDynamicParameters() 拼接
Fv 名义nominal_friction_from_urdf()URDF <dynamics damping> → model.damping[joint_id]
Fc 名义同上URDF 无库仑项 → 报告里记 0
Pinocchio 4 注意：旧版 pin.standardParameters(model) 已移除。 本仓库用 toDynamicParameters() 提取与 regressor 列一致的 10 维标准惯性参数 （mass, mc_x…mc_z, Ixx…Izz）。见 Pinocchio Overview。

3. 合成数据集：已知真值 → 假装「测到了 τ」

Issue 02 在接 Gazebo/实机 bag 之前，先用仿真真值验证回归流水线。循环在 generate_synthetic_dataset()：

  1. 按 sample_dt_s（默认 0.01 s）采样 num_periods 个激励周期；
  2. trajectory.sample(t % period) 得四关节 q, q̇, q̈；
  3. stack_state_from_sample 填入 Pinocchio 的 q, v, a（gripper 保持 neutral=0）；
  4. 真值力矩：tau_full = pin.rnea(...)（动力学） + Fv·q̇ + Fc·sign(q̇) + 高斯噪声；
  5. 只保留 Arm 四分量 tau_arm，并堆一行 Y。
tau_arm = (
    tau_full[arm_indices]
    + fv * arm_velocity
    + fc * velocity_sign(arm_velocity)
    + rng.normal(0.0, noise_std, 4)
)

合成用的摩擦真值在 default_synthetic_friction()：Fv = URDF damping + 小偏移，Fc 为固定常数（便于检验回归能否找回）。

为何用 RNEA 生成 τ 而不是 Y·φ？ 两者在数学上等价（无噪声时 τ = Y_dyn·φ）。 用 RNEA 更贴近「将来从传感器读 τ」的路径；回归仍用 Y 去拟合，检验整个辨识链。

4. 最小二乘与数值诊断

堆叠 N 个时刻后：

Y_stack ∈ R^{(4N) × 68} ,   τ_stack ∈ R^{4N}
π̂ = lstsq(Y_stack, τ_stack)

质量指标（run_synthetic_regression 末尾）：

  • 残差范数 ||Y_stack π̂ − τ_stack|| — 拟合好坏；
  • 有效秩 effective_rank_and_condition() — SVD 奇异值 > 1e-6·σ_max 的个数；
  • 有效条件数 σ_max / σ_rank — 有限值，避免满矩阵 cond=∞。
重要现象（4-DOF 臂）：68 列参数中只有约 30 维可辨识（有效秩 ≈ 30）。 大量 BIP 组合在动力学上冗余 → 单个连杆 mass 的估计值可能偏离 URDF， 但摩擦 Fv/Fc 通常恢复很好，且 Yπ̂ 仍能在最小二乘意义下拟合 τ。 报告 HTML 中已说明；Phase 1 不做 SymPy 符号重组。
