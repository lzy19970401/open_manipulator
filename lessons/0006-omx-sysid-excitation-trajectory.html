OpenMANIPULATOR-X 参数辨识：傅里叶激励轨迹（Issue 01）

第 5 课走读了重力补偿——已知 URDF 模型，算 g(q) 并前馈。 本课进入 System identification 流水线的第一步： 设计激励轨迹 q(t)，使后续录到的 (q, q̇, q̈, τ) 能线性回归出 BIP 与摩擦参数。 对照仓库包 open_manipulator_sysid 与 excitation_trajectory.py，把理论公式 ↔ 代码流程一一对应。

与 MISSION 的关系：重力补偿假设「模型已知」；参数辨识回答「模型里哪些数还不准、如何用实验估出来」。 独立包 open_manipulator_sysid 不修改 GC / bringup yaml（见 ADR-0001）。

1. 为什么要「激励轨迹」？

完整关节动力学可写成：

M(q) q̈ + C(q,q̇) q̇ + G(q) + F(q̇) = τ

离线辨识的核心技巧：把上式整理成线性回归

Y(q, q̇, q̈) · π = τ

其中 π 堆叠 BIP（最小惯性参数）与 Fv、Fc（摩擦系数）。 若 q(t) 运动贫乏（例如一直停在 q₀），Y 的列高度相关 → 参数不可辨识。 工业常用多频傅里叶轨迹，使各 regressor 列被持续激励（persistent excitation）。 主参考：Swevers et al., Robotica 1997 — optimal robot excitation for parameter identification.

2. 理论：多频傅里叶 q(t)

对 Arm 每个关节 j（本包仅 joint1–4）：

q_j(t) = q₀_j + Σ_{k=1}^{N} a_{jk} sin(k ω₀ t + φ_{jk})
ω₀ = 2π / T

对时间求导（链式法则，代码里逐项累加）：

q̇_j  = Σ a_{jk} · k ω₀ · cos(k ω₀ t + φ_{jk})
q̈_j  = −Σ a_{jk} · (k ω₀)² · sin(k ω₀ t + φ_{jk})

Phase 1 默认（config/excitation.yaml）：N=5，T=10 s，q₀ 为各关节硬限位中点， 总位置幅值 = 限位行程的 30%，再按 1/k 分给各谐波；φ=0 使 t=0 时 sin=0 → q(0)=q₀。

3. 代码总览：从 yaml 到 sample(t)

步骤 函数 / 文件 做什么
1 读配置 from_yaml() → __init__() 解析关节列表、限位、q₀、N/T、安全上限
2 算限位 __init__ 内循环 硬限位 → 软限位（内缩 10%）→ 存 JointSafetyLimits
3 分配谐波幅值 _build_harmonics() 每关节总幅值 × 1/k 权重 → 未缩放 ajk
4 安全缩放 _compute_amplitude_scale() 统一系数 s，使位置/速度/加速度解析上界不超限
5 求 q,q̇,q̈ sample(t) → _joint_kinematics() 四关节各自傅里叶求和，返回 TrajectorySample
6 校验 validate_period() 一个周期内密采样；超限 → SafetyViolation

4. 走读：构造阶段（__init__）

ExcitationTrajectory.from_yaml(path) 读入 yaml 后，在 __init__ 中：

  1. 锁定 Arm 四关节 — arm_joints 必须等于 ARM_JOINTS，拒绝 Gripper。
  2. ω₀ — self._omega0 = 2 * pi / period_s（对应公式 ω₀=2π/T）。
  3. 软限位 — 对 URDF 硬限位 [lower, upper]，内缩 10%： soft_lower = lower + inset*span，soft_upper = upper - inset*span。
  4. 谐波幅值 — _build_harmonics()： 权重 w_k = 1/k，归一化后 a_k = (0.3 × 全行程) × w_k / Σw。
  5. 缩放 — _compute_amplitude_scale() 取所有关节、所有约束的最小比例 s：
    • 位置：Σa_k ≤ min(q₀−soft_lo, soft_hi−q₀)
    • 速度：Σ a_k · k · ω₀ ≤ 1.0 rad/s
    • 加速度：Σ a_k · k² · ω₀² ≤ 2.0 rad/s²
    实际幅值 = s × a_k（存于 _scaled_amplitudes）。默认配置 s≈0.39，因 joint1 速度约束最紧。
解析界 vs 数值校验：缩放用三角恒等式上界（各谐波同相叠加）保守估计； validate_period(2000) 再密采样确认软限位与速度 cap——单元测试依赖后者。

5. 走读：采样 _joint_kinematics(joint, t)

这是公式直接落地处（excitation_trajectory.py 约 220–236 行）：

q   = q0
qd  = 0
qdd = 0
for amp, harmonic, phase in zip(amps, range(1, N+1), phases):
    omega = harmonic * omega0          # k · ω₀
    angle = omega * t + phase
    q   += amp * sin(angle)            # 位置项
    qd  += amp * omega * cos(angle)    # 一阶导 → q̇
    qdd += -amp * omega**2 * sin(angle) # 二阶导 → q̈

sample(t) 对四个关节各算一组 (q, q̇, q̈)，打包为不可变 dataclass TrajectorySample。 下游 Issue 02 的 Pinocchio regressor 需要的就是这三组量 + 测得 τ。

6. 走读：安全校验 _validate_state

在线实验（Issue 03/04）若关节超出软限位或 |q̇|>1.0 rad/s，应中止激励（User Story 8）。 离线生成器用同样规则自检：

  • q ∉ [soft_lower, soft_upper] → SafetyViolation
  • |q̇| > max_velocity → SafetyViolation
  • |q̈| > max_acceleration → SafetyViolation（Phase 1 默认 2.0 rad/s²）

main() CLI 在打印前先调用 validate_period()，保证默认 yaml 可安全用于 Gazebo/实机流程。
