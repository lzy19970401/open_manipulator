2. 一帧 update() 的数据流

核心公式（Issue 01 纯重力，摩擦默认关）：

τ_cmd_i = effort_sign_flips_i × torque_scaling_factors_i × G_i(q)

3. 生命周期：四段代码各干什么

A on_configure — 建模型、建索引（只做一次）

  1. 读参数：joints（Arm 四关节）、passive_state_joints（至少 gripper_left_joint）
  2. 从 get_robot_description() 取 URDF 字符串 → pinocchio::urdf::buildModelFromXML
  3. 为每个 ros2_control 关节名查 Pinocchio 的 idx_q（填 q）和 idx_v（读 G 的分量）
pinocchio::urdf::buildModelFromXML(urdf, model_);
data_ = std::make_unique<pinocchio::Data>(model_);

const pinocchio::JointIndex joint_id = model_.getJointId("joint1");
arm_velocity_indices_.push_back(model_.joints[joint_id].idx_v());
arm_configuration_indices_.push_back(model_.joints[joint_id].idx_q());
idx_q vs idx_v：OMX 全是 1-DoF 关节，两者数值常相同，但 API 上 q 用 idx_q，data.g 按速度空间 idx_v 索引——混用会 silent wrong。

B command / state interface 声明 — 谁被命令、谁只读

关节commandstate
joint1–joint4effortposition, velocity
gripper_left_joint（无）position 只读

command_interface_configuration() 只列出 Arm； state_interface_configuration() 额外加上 passive 夹爪的 position。 Gripper 仍由硬件侧 position/current 模式控制，GC 插件不碰其 effort。

C fill_configuration_vector — 组装完整 q

q = pinocchio::neutral(model_);
q[arm_configuration_indices_[i]]   = arm_state position;
q[passive_configuration_indices_] = gripper_left position;

// 实机 ros2_control 无 gripper_right 状态 → 按 URDF mimic 镜像
q[idx_q(gripper_right)] = q[idx_q(gripper_left)];

Pinocchio 模型 nq=6（四旋转 + 两棱柱夹爪指）。夹爪质量会影响 Arm 上 G(q)； 若只填 Arm 四关节、忽略夹爪，腕部力矩会偏差。 实机只暴露 Master finger，所以在代码里显式 mirror Mimic finger。

D update() — 算力矩并下发

pinocchio::computeGeneralizedGravity(model_, *data_, q);

for each arm joint i:
  tau_phys = data_->g[arm_velocity_indices_[i]];
  // enable_friction_compensation 时叠加 Fv·q̇ + Fc·sign_ε(q̇)（Issue 02）
  effort = effort_sign_flips[i] * torque_scaling_factors[i] * tau_phys;
  joint_command_interface_[0][i].set_value(effort);

与 KDL 版不同：这里直接调用 computeGeneralizedGravity， 不用 RNEA + 把 q̇/q̈ 置零的间接写法；也不订阅 /collision_flag 或 follower /joint_states。

E on_deactivate — 安全清零

四个 Arm effort 接口全部 set_value(0.0)，配合 launch 退出时的 gc_shutdown_torque_disable。

  1. 打开 pinocchio_gravity_compensation_controller.cpp，找到 update() — 确认只有一条 Pinocchio 动力学调用
