关节空间阻抗控制：数学原理与代码对应

第 10 课 的 GC 只前馈重力（可选 Coriolis/摩擦），关节近似「自由漂浮」。 本课解释 Pinocchio 关节阻抗控制器 如何在同一 effort 栈上， 对参考构型 qd 施加虚拟弹簧–阻尼，并用 computed torque 抵消机器人自身动力学。

先修：刚体动力学方程、Pinocchio rnea、ros2_control effort 接口。 设计决策见 ADR-0002。

1. 从动力学方程出发

开链机械臂在关节空间的欧拉–拉格朗日方程（无外力时）：

M(q) q̈ + C(q, q̇) q̇ + g(q) = τ
符号含义Pinocchio
M(q)对称正定惯量矩阵crba / 含于 rnea
C(q,q̇)q̇Coriolis + 离心项nonLinearEffects 或 rnea(q,v,0)−g
g(q)广义重力computeGeneralizedGravity
τ关节力矩（控制输入）→ ros2_control effort

主教材：Modern Robotics Ch.8； Pinocchio 逆动力学：rnea 文档。

2. 关节空间阻抗：虚拟弹簧–阻尼

在关节 i 上并联一个「虚拟」弹簧（刚度 Kj,i）和阻尼（Dj,i），平衡点为参考角 qd,i：

τimp,i = Kj,i (qd,i − qi) + Dj,i (q̇d,i − q̇i)

物理直觉：偏离 qd 时产生恢复力矩；有速度时阻尼耗散能量，抑制振荡。Phase 1 默认 Kj = [2, 2, 1.5, 1] N·m/rad，Dj = [0.5, 0.5, 0.3, 0.2] N·m·s/rad。

与 GC 对比：GC 等价于 Kj = Dj = 0（仅前馈，无回弹）；阻抗在 qd 附近「软 hold」。

3. Computed torque：为何用 rnea

若只加 τimp 而不补偿 M、C、g，真实关节会像「在可变惯量下挂弹簧」——手感随构型变化。标准做法是 computed torque（逆动力学前馈 + 阻抗反馈）：

τ = M(q) q̈d + C(q,q̇) q̇ + g(q) + Kj(qd − q) + Dj(q̇d − q̇) + τf

Pinocchio 的递归牛顿–欧拉算法 rnea(model, data, q, v, a) 恰好计算

rnea(q, v, a) = M(q) a + C(q,q̇)q̇ + g(q)

因此令 a = q̈d（代码里向量 ddq），前馈项为 data.tau，再叠加阻抗与摩擦：

pinocchio::rnea(model_, *data_, q, v, ddq);   // 前馈
τ_i = data.tau[i_v]
    + K_i * (q_d_active_i - q_i)
    + D_i * (q_d_dot_active_i - qdot_i)
    + τ_friction_i

对应实现：impedance_control_law.hpp 中 compute_joint_impedance_torque； 主循环见 pinocchio_impedance_controller.cpp 第 148–180 行。

B 插值器（Phase 2 接 topic 前已预埋）

qd 不允许阶跃，否则 M(q)Δq̈ 与 KΔq 会在一帧内产生力矩尖峰。内部维护：

  • q_d_target — 目标（Phase 1 仅在 activate 设置）
  • q_d_active — 每周期实际用于控制的参考
|qd,active,i − qd,target,i| ≤ vmax,i · Δt  （逐关节限速，默认 0.5 rad/s） 
step_reference_interpolation(q_d_active, q_d_dot_active, q_d_target, max_velocity, dt);

q̇d、q̈d 由差分得到，填入 ddq 供 rnea — 参考轨迹移动时前馈仍一致。

5. 摩擦与硬件映射

与 Pinocchio GC 相同线性模型（可选）：

τf,i = Fvi q̇i + Fci signε(q̇i)

sign_ε：|q̇| < deadzone 时为 0，避免静摩擦抖动。见 sign_with_deadzone。

下发舵机前：

τcmd,i = si · αi · τphys,i

effort_sign_flips = si，torque_scaling_factors = αi（与 GC yaml 同源）。

9. 自测（检索练习）

不看上文，尝试写出 Phase 1 hold 点（q̇d=0, q̈d=0）时的完整 τ 公式，并说明 rnea 在该情况下等价于哪一项之和。

参考答案
τ = C(q,q̇)q̇ + g(q) + Kj(qd − q) − Dj q̇ + τf

rnea(q,v,0) = C(q,q̇)q̇ + g(q)（无 q̈ 项）。
