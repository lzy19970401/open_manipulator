摩擦辨识 regress.py：URDF 惯性 + 只估 Fv/Fc

第 7 课走读了「68 维标准惯性 + 摩擦」联合回归（有效秩约 30，BIP 不可靠）。 当前 regress.py 已改为 ADR 混合路线： 惯性固定为 URDF，用 RNEA 减掉动力学，只对 8 个摩擦未知数 做最小二乘。

与第 7 课的区别：第 7 课描述旧版 computeJointTorqueRegressor 全列回归； 本课对应当前仓库。速查表已同步更新。
产品语义（Calibrated dynamics model）： 惯性 → URDF；摩擦 → 辨识结果写入 friction_estimated.yaml（Phase 2 可拷到 calibrated_dynamics.yaml）。见 ADR-0001。

1. 完整模型 vs 我们实际回归什么

Arm 四关节完整动力学：

M(q) q̈ + C(q,q̇) q̇ + G(q) + F(q̇) = τ

Pinocchio pin.rnea(model, data, q, v, a) 一次算出无摩擦的广义力矩 τdyn（含 M、C、G）。摩擦单独建模：

τ_f,i = Fv_i · q̇_i + Fc_i · sign(q̇_i)

测量（或合成）力矩：

τ_meas = τ_dyn,URDF + τ_f + noise

回归时不估惯性，先减动力学：

τ_res = τ_meas − τ_dyn,URDF = Y_fric · π_fric

其中 π_fric = [Fv₁…Fv₄, Fc₁…Fc₄]ᵀ，仅 8 个未知数。

2. 摩擦回归矩阵 Y_fric（4×8）

每个采样时刻，对 Arm 四行方程：

τ_res = [ q̇₁  0    0    0   | s₁  0   0   0 ] [ Fv₁ ]
         [  0  q̇₂  0    0   |  0  s₂  0   0 ] [ Fv₂ ]
         [  0   0  q̇₃  0   |  0   0  s₃  0 ] [ Fv₃ ]
         [  0   0   0  q̇₄  |  0   0   0  s₄ ] [ Fv₄ ]
                                                [ Fc₁ ]
                                                [ Fc₂ ]
                                                [ Fc₃ ]
                                                [ Fc₄ ]

s_i = sign(q̇_i)，|q̇_i| < 1e-3 时 s_i = 0（velocity_sign 死区，避免静止点 sign 不定义）。

代码（build_friction_regressor_row）：

np.hstack([
    np.diag(arm_velocity),
    np.diag(velocity_sign(arm_velocity)),
])

3. 代码流水线（对照函数名）

步骤函数数学 / 作用
1 load_model URDF → Pinocchio model；gripper 仍在模型里，Arm 用 arm_indices 取四行
2 stack_state_from_sample 第 6 课 TrajectorySample → 全模型 q, v, a（gripper 保持 neutral 0）
3 dynamics_torque_arm τ_dyn = pin.rnea(...)[arm_indices] — 固定 URDF 惯性
4 generate_synthetic_dataset 合成 τ_meas；τ_res = τ_meas − τ_dyn；堆 Y_fric 行
5 solve_least_squares π̂ = argmin ‖Y_stack π − τ_res‖
6 split_friction_vector π̂ 前 4 → Fv，后 4 → Fc
7 write_* yaml + HTML 报告

4. 合成数据循环（Issue 02 示踪弹）

generate_synthetic_dataset 内层（实机/Gazebo 将来替换 τ_meas 来源即可）：

tau_dyn = dynamics_torque_arm(...)           # URDF
tau_friction = fv*qdot + fc*sign(qdot)       # 真值 Fv,Fc
tau_meas = tau_dyn + tau_friction + noise
tau_residual = tau_meas - tau_dyn            # ≈ 摩擦 + 噪声
rows.append(build_friction_regressor_row(qdot))

真值摩擦在 default_synthetic_friction：Fv = URDF damping + 小偏移，Fc 为常数（便于验收）。

5. 最小二乘与数值指标

Y_stack ∈ R^{(4N)×8},   τ_res,stack ∈ R^{4N}
π̂ = lstsq(Y_stack, τ_res,stack)
residual = ‖Y_stack π̂ − τ_res,stack‖

effective_rank_and_condition：对 Y_stack 做 SVD，奇异值 > 10⁻⁶·σ_max 的个数为有效秩。 合成 run 典型值：8/8，条件数约 9（远好于旧版 ~21000）。

指标含义合成 run 典型
residual_norm拟合 τ_res 的误差；含噪声时 ≈ √(4N)·σ_noise~0.55（σ=0.005）
matrix_rankY 列空间维数8
condition_numberσ_max / σ_rank~9.4
残差大 ≠ 摩擦估坏了：0.55 Nm 量级主要来自 12000 行上的高斯噪声能量； 看 friction_estimated.yaml 里 Fv/Fc 与 synthetic_truth 是否接近。

7. 实机/Gazebo 时同一公式

将来 bag 里只有 τ_meas、q、q̇、q̈ 时，流程不变：

  1. 用 URDF + Pinocchio 算 τ_dyn,URDF(q,q̇,q̈)；
  2. τ_res = τ_meas − τ_dyn；
  3. 同一 Y_fric、同一 lstsq。

若 URDF 惯量系统偏大/偏小，误差会泄漏进 Fv/Fc — 混合路线的前提是信任 URDF 惯性。
