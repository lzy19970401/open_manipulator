Pinocchio 关节阻抗速查

核心公式

M(q)q̈ + C(q,q̇)q̇ + g(q) = τ

τ = rnea(q, v, q̈_d) + K_j(q_d − q) + D_j(q̇_d − q̇) + τ_f

τ_cmd = effort_sign_flips ⊙ torque_scaling ⊙ τ

τ_f,i = Fv_i q̇_i + Fc_i sign_ε(q̇_i)   [可选]

update() 顺序

1. step_reference_interpolation → q_d_active, q_d_dot_active
2. step_reference_acceleration  → q_d_ddot_active
3. fill q, v (+ gripper mimic)
4. ddq[v_idx_i] = q_d_ddot_active[i]
5. rnea → data.tau
6. per joint: τ = tau + K*Δq + D*Δq̇ + friction
7. τ_cmd = sign × scale × τ → effort IF
