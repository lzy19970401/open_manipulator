Pinocchio GC 控制器流程速查

包与插件

项值
包om_pinocchio_gravity_compensation_controller
插件类型pinocchio_gravity_compensation_controller/PinocchioGravityCompensationController
配置目录open_manipulator_x_compensation_pinocchio
Launchopen_manipulator_x_pinocchio_gravity_compensation.launch.py

生命周期

on_configure:
  buildModelFromXML(robot_description) → Model + Data
  缓存 idx_q / idx_v（Arm + passive gripper）

on_activate:
  绑定 effort command（Arm）
  绑定 position/velocity state（Arm）
  绑定 position state（gripper_left）

update @ 100 Hz:
  fill q（Arm + gripper_left + mimic gripper_right）
  computeGeneralizedGravity → data.g
  τ_cmd = sign × scale × G_i(q)  [+ 可选 Fv/Fc]
  set effort command

on_deactivate:
  Arm effort → 0

接口矩阵

关节commandstate
joint1–4effortposition, velocity
gripper_left—position（被动）

关键公式

τ_cmd_i = effort_sign_flips_i × torque_scaling_factors_i × G_i(q)

// 摩擦开启时（Issue 02+）：
τ_phys = G_i + Fv_i·q̇_i + Fc_i·sign_ε(q̇_i)
