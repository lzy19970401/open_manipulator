傅里叶激励轨迹 · 公式与代码对照

动力学辨识目标

M(q)q̈ + C(q,q̇)q̇ + G(q) + F(q̇) = τ

Y(q, q̇, q̈) · π = τ  （线性回归：π = BIP + 摩擦参数）

单关节多频傅里叶（Phase 1 实现）

q_j(t) = q₀_j + Σk=1..N ajk sin(k ω₀ t + φjk)

ω₀ = 2π / T

q̇_j = Σ ajk k ω₀ cos(k ω₀ t + φjk)

q̈_j = −Σ ajk (k ω₀)² sin(k ω₀ t + φjk)
