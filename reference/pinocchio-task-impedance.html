Pinocchio 任务空间阻抗速查

核心公式（link1 系，仅 EE 位置）

ẋ = J_p(q) q̇
ẍ = J̇_p q̇ + J_p q̈

F = K_p ⊙ (x_d − x) + D_p ⊙ (ẋ_d − ẋ)

a_des = ẍ_d − J̇_p q̇

q̈_null,i = K_null,i (q_capture,i − q_i)

q̈_d = argmin  ‖W_task(J_p q̈ − a_des)‖² + ‖W_null(q̈ − q̈_null)‖²
       s.t. q̈_min ≤ q̈ ≤ q̈_max  (Arm only)

τ = rnea(q, v, q̈_d) + J_pᵀ F + τ_f
τ_cmd = effort_sign_flips ⊙ torque_scaling ⊙ τ

QP 矩阵（ProxQP）

H = 2 (J_pᵀ W_task J_p + W_null)
g = −2 (J_pᵀ W_task a_des + W_null q̈_null)
